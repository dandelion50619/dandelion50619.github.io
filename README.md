# 민들레 / Dandelion — portfolio

## 내용 고치기
1. https://app.pagescms.org 에 GitHub 계정으로 로그인
2. 이 저장소 선택
3. 왼쪽 메뉴에서 **작업 · 전시 · 작가노트 · 소개 · CV · 연락처** 를 고치고 **Save**

저장하면 1–2분 뒤 사이트에 반영돼요 (저장소의 Actions 탭에서 진행 상황을 볼 수 있어요).

## 사진
- JPG / PNG / WebP 를 올려 주세요. 원본 화질 그대로 보여요.
- 목록용 작은 사진은 게시할 때 자동으로 만들어져요. 따로 올릴 필요 없어요.
- 작업 하나에 사진을 여러 장 넣을 수 있고, 첫 번째 사진이 대표 사진이에요.

## 파일 구성
- `data/` — 글과 목록 (works, exhibitions, statement, about)
- `media/` — 사진 원본
- `index.html` — 사이트 화면
- `.pages.yml` — 관리 페이지 설정
- `.github/workflows/pages.yml` — 자동 게시
